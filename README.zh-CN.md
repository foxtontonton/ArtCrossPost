# ArtCrossPost（多平台艺术创作同步分发工具）

一款免费、开源的 Windows 桌面客户端：同一幅作品，只写一次，一键分发到多个平台。

[English](README.md)

## 为什么做 ArtCrossPost？

在每个平台重复上传同一张图、重复填写标题/标签/描述，既慢又容易出错。
ArtCrossPost 把作品、文案和各平台的差异化版本集中在一个本地工作区里，
通过本地 Playwright 浏览器会话完成发布——不依赖付费平台 API、没有 API 月费，
登录状态只保存在你自己的电脑上。

## 核心特性

- **一稿多发**：内置 **DeviantArt**、**X (Twitter)**、**Patreon**、**Ko-fi** 分发器。
- **DeviantArt 单作品多图**：一个 deviation 发布多张图（默认上限 10 张，可配置）；
  标题、描述、标签、相册与 Mature/AI 标记只填一次；发布后自动核对实际张数与预期是否一致。
- **本地 AI 自动打码**：ONNX NudeNet 检测，自动生成合规版本（黑条 / 马赛克 / 高斯模糊，
  覆盖范围可调，支持画布手动交互微调）；允许原图的平台仍可发送原图。
- **水印**：文字水印的字体、字号、透明度、位置均可配置，只加在需要的副本上。
- **实时预览与 GIF 优化**：三栏暗色界面，响应式合成预览画布与 GIF 压缩优化，
  动图发布前可实时预览并校验体积。
- **分平台控制**：敏感内容标记、可见范围/赞助档位、单图体积上限（超限才压缩）、
  发布护栏与出库成功真实断言——不是"发出去就算完"。
- **预设与签名**：常用标签、各平台偏好可保存复用；可一键追加 Patreon / Ko-fi 等赞助引流签名。
- **本地优先、注重隐私**：会话、预设、窗口状态都存在本地 `data/` 目录（已被 .gitignore 排除）；
  除你明确发布的帖子外，不向任何地方上传数据。

## 运行环境

- Windows 10/11
- Python 3.10+
- Microsoft Edge（Playwright 自动化使用）

## 快速启动

双击 `start.bat`，或在终端运行：

```bash
pip install -r requirements.txt
python app.py
```

首次使用时在软件的浏览器窗口里登录各平台，登录状态会保存在本地供后续使用。
