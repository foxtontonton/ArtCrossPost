# ArtCrossPost（多平台艺术创作同步分发工具）

一款免费、开源的 Windows 桌面客户端：同一幅作品，只写一次，一键分发到多个平台。

[English](README.md)

## 为什么做 ArtCrossPost？

在每个平台重复上传同一张图、重复填写标题/标签/描述，既慢又容易出错。
ArtCrossPost 把作品、文案和各平台的差异化版本集中在一个本地工作区里，
通过本地 Playwright 浏览器会话完成发布——不依赖付费平台 API、没有 API 月费，
登录状态只保存在你自己的电脑上。

## 核心特性

- **一稿多发**：内置 **DeviantArt**、**X (Twitter)**、**Patreon** 分发器。
  （Ko-fi 分发器保留在代码中，默认禁用，可通过 `platform_kofi_enabled` 重新启用。）
- **DeviantArt 单作品多图**：一个 deviation 发布多张图（默认上限 10 张，可配置）；
  标题、描述、标签、相册与 Mature/AI 标记只填一次；发布后自动核对实际张数与预期是否一致。
- **缩略图拖拽排序**：拖动即可调整图集顺序，带实时插入指示线；
  新顺序自动同步到 X 选用图与各平台的实际发送顺序。
- **GIF 智能优化**：超限 GIF 先降分辨率（每档从原图重采样，下限为长边 640px / 50%），
  再降色彩，最后才抽帧——画质损失最小的顺序。
- **X 预告帖格式**：按 Twitter-Text 官方加权算法计算 280 字符上限；
  X 上发布正文预告（只在句号处截断）+ 🔞 NSFW 提示与 DeviantArt 外链 + 标签，
  DA 与 Patreon 仍发全文。界面提供**实时预览**，输入时即可看到 X 最终文案与加权字数。
- **定时发布**：一键快照当前帖子（图片、顺序、文案、平台），到点自动发布；
  程序关闭期间错过的任务会在下次启动时弹窗提醒，绝不静默丢弃。
- **失败平台单独重试**：某个平台发布失败时，只重试它一个，复用已渲染的图片与文案快照；
  已成功的平台绝不重复发帖。
- **发布历史与重复预警**：每次发布自动记录（带图片感知指纹）；
  导入曾经发过的图集时顶部横幅提醒，防止手滑重复发。
- **文件夹批量导入自动分组**：导入整个文件夹后，按文件名规律（同前缀+序号、Vol.N、
  章节号）自动拆成多个待发帖，审核弹窗里可合并 / 拆分 / 改名后再载入。
- **数据导出 / 导入**：配置、草稿、登录态、定时任务、发布历史一键打包为 zip 备份或迁移；
  导入前自动备份现有数据。
- **本地 AI 自动打码**：ONNX NudeNet 检测，自动生成合规版本（黑条 / 马赛克 / 高斯模糊，
  覆盖范围可调，支持画布手动交互微调）；允许原图的平台仍可发送原图。
- **水印**：文字水印的字体、字号、透明度、位置均可配置，只加在需要的副本上。
- **实时预览**：三栏暗色界面，响应式合成预览画布，动图发布前可实时预览并校验体积。
- **分平台控制**：敏感内容标记、可见范围/赞助档位、单图体积上限（超限才压缩）、
  发布护栏与出库成功真实断言——不是"发出去就算完"。
- **预设与签名**：常用标签、各平台偏好可保存复用；可一键追加赞助引流签名。
- **本地优先、注重隐私**：会话、预设、窗口状态都存在本地 `data/` 目录（已被 .gitignore 排除）；
  除你明确发布的帖子外，不向任何地方上传数据。

## 运行环境

- Windows 10/11
- Python 3.10+
- Microsoft Edge（Playwright 自动化使用）

## 快速启动

双击 `start.bat`，或在终端运行：

```bash
pip install -r requirements.txt
python app.py
```

首次使用时在软件的浏览器窗口里登录各平台，登录状态会保存在本地供后续使用。
